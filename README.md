# AI Hardware Advisor Sanity Rules

This example simulates an AI-powered hardware advisor. It demonstrates how a system can "explore every path" by iterating through various component combinations and then apply "sanity rules" to validate recommendations. The rules consider budget, use case, and component compatibility to provide reliable and practical hardware suggestions.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`.
Follow the prompts to enter your budget and use case.
